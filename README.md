# Civilian Protocol: downloads

Playtest builds of Civilian Protocol, an extraction survival game about getting home, and who is waiting there. Made by RootBros Gaming.

**[Open the download page](https://treybros.github.io/civilian-protocol-downloads/)**, or take the newest build directly:

- [Windows](https://github.com/TreyBros/civilian-protocol-downloads/releases/latest/download/CivilianProtocol-windows.zip)
- [Mac](https://github.com/TreyBros/civilian-protocol-downloads/releases/latest/download/CivilianProtocol-mac.zip)
- [Linux](https://github.com/TreyBros/civilian-protocol-downloads/releases/latest/download/CivilianProtocol-linux.zip)

## Start it

- **Windows:** unzip the whole folder and run `CivilianProtocol.exe`. If a blue "Windows protected your PC" box appears, click More info, then Run anyway. The build isn't signed yet.
- **Mac:** unzip it and move Civilian Protocol to Applications. The first time, right-click the app, choose Open, then Open again.
- **Linux:** unzip it, then run `CivilianProtocol.x86_64`.

Everyone playing together needs the same version. It is on the title screen. `READ-ME-FIRST` in each zip says how to play together and how to report a problem.

This repository holds only the builds and this page. The game's source is not here.
